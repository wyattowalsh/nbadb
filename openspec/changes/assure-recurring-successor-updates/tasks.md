Tasks are dependency ordered. A checked item records evidence already produced
in this worktree; it does not authorize network access, commit, push, extraction,
publication, or human attestation. Partially implemented legacy/private
`successor_*` code does not close a one-repository task. The current Kaggle
dataset is not an admissible full-model parent. Every live, external, remote, and
manual gate remains open until its exact immutable receipt exists.

├── B fresh full-model public-parent admission
├── C three-part recurring scope + durable coordinator
└── D public-safe result/field authority
    B + C + D -> E stable transaction + isolated replacement candidate

    B..H -> I CLI/workflows/readback/human/docs/final-join tooling
    I -> J local assurance + independent review

Independent leaves in the same lettered wave SHOULD run in parallel. A single

Git index, or publication authority. Every dispatch MUST be resolved before its
join, and every join requires the named immutable receipts rather than merely a
successful process exit.
